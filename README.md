# Victor Basov Portfolio

This is a modern portfolio website built with **React 19**, **Vite**, **Material UI (MUI)**, and **SCSS**. It showcases my projects, work experience, and contact information.

---

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or newer recommended)
- [pnpm](https://pnpm.io/) (preferred) or npm/yarn

### Install dependencies

With pnpm:
```sh
pnpm install
```
Or with npm:
```sh
npm install
```

### Start the development server

With pnpm:
```sh
pnpm dev
```
Or with npm:
```sh
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

### Build for production

With pnpm:
```sh
pnpm build
```
Or with npm:
```sh
npm run build
```

### Preview the production build
```sh
pnpm preview
```

### Run tests
```sh
pnpm test
```

## 📦 Deployment

This site is configured for static deployment (e.g., GitHub Pages) using Vite. To deploy:

```sh
pnpm run build
pnpm run deploy
```
